# Simple Transliteration Rules for Modern Hebrew (Israeli Pronunciation)

**Version:** Practical and simple for LLM use (2026)  
**Goal:** Faithfully represent current Israeli Hebrew pronunciation (Sephardi/Ashkenazi blended modern standard) using only standard keyboard letters — no complex diacritics (no ḥ, ṭ, š, ʾ, ʿ, macrons, etc.).

## General Principles (apply to both languages)

- Use only basic Latin letters from a standard keyboard.
- Faithful to modern Israeli pronunciation (not biblical or ancient).
- Sheva (ְ) → short "e" or omitted if very weak (e.g., Bnei Brak → Bnei Brak).
- Avoid unnecessary apostrophes (Beer Sheva instead of Be'er Sheva).
- Word-initial ה is always "h".
- Word-final ה after a vowel should be rendered as "ah/eh/ih/oh/uh" (i.e., keep the vowel and add "h").
- Capitalize proper names normally.
- Very common established names (David, Israel, Abraham) may keep traditional spelling due to widespread use, but prefer faithful transliteration when possible.

## 1. Simple Transliteration to Spanish

### Consonants

| Hebrew | Modern Israeli sound    | Spanish simple        | Example           |
| ------ | ----------------------- | --------------------- | ----------------- |
| א      | mute or light glottal   | (omit)                | Avraham → Abraham |
| בּ     | b                       | b                     | Baruj → Baruj     |
| ב      | v                       | v                     | Havdala → Havdala |
| ג      | g (as in "gato")        | g                     | Gadol → Gadol     |
| ד      | d                       | d                     | David → David     |
| ה      | h or mute at end        | h (omit at end often) | Hilel → Hilel     |
| ו      | v / u / o               | v / u / o             | Shavuot → Shavuot |
| ז      | z (like "s" in "casa")  | z                     | Zman → Zman       |
| ח      | strong guttural "j"     | j                     | Januka → Januka   |
| ט      | t                       | t                     | Tisha → Tisha     |
| י      | y / i                   | i / y                 | Yisrael → Yisrael |
| כּ     | k                       | k / c (before a,o,u)  | Kadosh → Kadosh   |
| כ/ך    | guttural "j"            | j                     | Mijael → Mijael   |
| ל      | l                       | l                     | Lajaim → Lajaim   |
| מ      | m                       | m                     | Mitzva → Mitzva   |
| נ      | n                       | n                     | Najash → Najash   |
| ס      | s                       | s                     | Simja → Simja     |
| ע      | guttural (usually mute) | (omit)                | Yaakov → Yaakov   |
| פּ     | p                       | p                     | Pesaj → Pesaj     |
| פ      | f                       | f                     | Shofar → Shofar   |
| צ/ץ    | ts                      | tz                    | Tzion → Tzion     |
| ק      | k                       | k / c                 | Kineret → Kineret |
| ר      | r (rolled or uvular)    | r / rr                | Rosh → Rosh       |

| שׂ     | s                       | s                     | Sfarad → Sfarad   |
| ת      | t                       | t                     | Talmud → Talmud   |

### Vowels (approximation)

- ַ / ָ → a
- ֵ / ֶ → e
- ִ → i
- ֹ / וּ / ֻ → o / u
- ְ → e (or omit)

Do not use accents or diacritics in Spanish (Shabat, Torah, Mitzva, Tzedaka, Januka, Yerushalaim).

### Key Examples (Spanish)

- יְרוּשָׁלַיִם → Yerushalaim
- חֲנֻכָּה → Januka
- שַׁבָּת → Shabat
- מִצְוָה → Mitzva
- צְדָקָה → Tzedaka
- יַעֲקֹב → Yaakov
- יִשְׂרָאֵל → Yisrael
- תּוֹרָה → Torah
- פֶּסַח → Pesaj
